# @mongodb-js/agent-engine-sdk

[![License](https://img.shields.io/badge/license-Apache--2.0-blue.svg)](LICENSE.md)

Core TypeScript protocols, models, schemas, and clients shared by Atlas Agent
Engine SDK integrations. The package has no dependency on the platform runtime
and can be used to define agent, execution, message, tool, and LLM contracts in
an independent application.

## Install

```bash
npm install @mongodb-js/agent-engine-sdk
```

The package exports the core types and runtime schemas from its root entry point.
See the [API reference](docs/api.md) for the full
exported surface.
